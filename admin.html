Belépés GitHub-tokennel

A jóváhagyások közvetlenül a GitHub-tárolóba mentődnek, ehhez egy hozzáférési token kell.

Hogyan készítsek tokent?
  1. GitHubon kattints jobb felül a profilképedre, majd: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Adj nevet (pl. „jóváhagyás”) és lejáratot.
  3. Repository access: Only select repositories → válaszd a diak-lehetosegek tárolót.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, majd másold ide. A token csak ehhez az egy tárolóhoz ad hozzáférést.
